# Time & Work — Resources

Curated external links for further reading, extra practice, and video explanations on Time & Work
aptitude problems (combined work, efficiency ratios, pipes & cisterns, workers joining/leaving,
wages, and alternate-day working).

## 🧭 How to Use These Resources

1. Start with this repo's own `notes/` files for the core method — they're self-contained:
   `01-fundamentals.md` (Work = Rate × Time, combined work, efficiency), `02-fast-tricks-and-
   shortcuts.md` (LCM method, worker-day tricks, all the speed techniques), and
   `03-question-pattern-catalog.md` (every question phrasing you'll meet, grouped by which trick
   solves it).
2. Use IndiaBIX / PrepInsta / Testbook for **volume practice** once the method is clear.
3. Watch the YouTube video above if you prefer a spoken walkthrough of the LCM method or the
   rate-first ratio trick.
4. Use IndiaBIX's Data Sufficiency set to practice the "CAT-style" reasoning variant of Time & Work
   questions, which is different from direct compute-the-answer questions.
5. ⚠️ A note on external sources: many coaching sites present dozens of named "rules" (Rule 1, Rule
   2, ... Rule 19, etc.) as if they were independent formulas. Nearly all of them collapse into the
   single `Work = Rate × Time` identity from `01-fundamentals.md` — treat named "rules" as
   pattern-matching shortcuts on top of that one formula, not as separate things to memorize from
   scratch.
